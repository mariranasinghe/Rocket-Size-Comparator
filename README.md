# 🚀 Rocket Size Comparator

Ever wondered how a Falcon 9 stacks up against a Starship, or how tiny a launch vehicle looks next to a giant rocket beast?  
**Rocket Size Comparator** makes it easy to compare rocket sizes in a fun, visual, and easy-to-digest way.

## ✨ What It Does

This project lets you compare rockets side by side so you can quickly see differences in size, scale, and presence. It turns boring numbers into something much more fun to explore.

## 🎯 Features

- Compare rockets visually.
- See size differences at a glance.
- Explore rocket data in a simple, friendly interface.
- Make space nerding out way more fun.
- Great for learning, demos, or just enjoying giant rockets.

## 🚀 Getting Started

### Clone the repo

```bash
git clone https://github.com/mariranasinghe/Rocket-Size-Comparator.git
cd Rocket-Size-Comparator
```

### Install dependencies

If this project uses npm:

```bash
npm install
```

### Run the app

If it's a static project, open `index.html` in your browser.

If it uses a dev server:

```bash
npm run dev
```

## 🛰️ How to Use

1. Open the app.
2. Pick the rockets you want to compare.
3. Watch the size showdown happen.
4. Enjoy the giant space vibes.

## 🌌 Why This Exists

Rocket dimensions can be hard to picture from numbers alone. This project helps make them feel real by showing scale in a fun and visual way.
